# Queit Bloom

Interactive visualization based on the Diffusion-Limited Aggregation algorithm using p5.js. Particles drift with Perlin noise and stick to a seed to form organic, branching structures.

## How to Run

Open `index.html` in a web browser. No build step required.

## Controls

| Action | Result |
|--------|--------|
| **Click** | Place the seed particle (where the tree grows from) |
| **Hold SPACE** | Pull particles toward the mouse + spawn new particles near the cursor |

## Tech

- [p5.js](https://p5js.org/) 1.9.0
