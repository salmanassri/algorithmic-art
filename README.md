# P5.js Project

A creative coding project using P5.js library.

## Getting Started

1. Open `index.html` in a web browser
2. The P5.js sketch will automatically load and run

## Files

- `index.html` - Main HTML file that loads P5.js and your sketch
- `sketch.js` - Your P5.js code goes here
- `Images/` - Folder containing image assets

## P5.js Resources

- [P5.js Reference](https://p5js.org/reference/)
- [P5.js Examples](https://p5js.org/examples/)
- [P5.js Learn](https://p5js.org/learn/)

## Tips

- The `setup()` function runs once when the program starts
- The `draw()` function runs continuously (like a loop)
- Use `mouseX` and `mouseY` to get the current mouse position
- Use `width` and `height` to get the canvas dimensions
